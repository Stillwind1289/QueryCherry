# QueryCherry starter
Responsive React + Vite prototype for QueryCherry, a browser-first toolkit for SQL, data, and developers.

## Included
- Responsive homepage and original cherry-inspired brand treatment
- Category pills and tool directory (no search/filter)
- Working local demos for SQL formatting, minification, and keyword case conversion
- Mobile navigation and responsive SQL editor
- Planned tools clearly labeled; no fake checkout or backend

## Run
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Production build: `npm run build`

## Notes
The SQL formatter is intentionally lightweight and not a complete SQL parser. Planned tools are placeholders. No backend, analytics, auth, or payments are configured yet. Before launch, add legal pages, test on real devices/browsers, and verify domain/trademark availability.
