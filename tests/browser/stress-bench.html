QueryCherry Browser & Memory Benchmark

Tests actual QueryCherry source functions using generated fake data. Measures execution time, correctness, input/output size, and JavaScript heap changes when the browser exposes memory information.

Safety first

This is a bounded performance test, not a crash-boundary test. Some operations may temporarily consume substantial memory or make the browser unresponsive.

  • Start with 1,000 rows.
  • Use 5,000 rows only if the first run completes comfortably.
  • Use 10,000 rows only on a device with sufficient available memory.
  • Save important work and close unnecessary tabs first.
  • Do not repeat large-file tests on a device that previously froze.

The benchmark cannot forcibly interrupt a synchronous operation after it starts. If the browser becomes unresponsive, wait rather than repeatedly tapping the Run button.

What the memory numbers mean

JavaScript heap measurements are estimates of memory used by JavaScript objects. They are not measurements of total device RAM or a guaranteed peak-memory reading. Results depend on the browser, device, garbage collection, and workload.

Some browsers do not expose JavaScript heap measurements. Timing and correctness tests can still run when memory reporting is unavailable.
